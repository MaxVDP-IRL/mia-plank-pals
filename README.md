# 🐶 Plank Pals

A tiny, offline-first web app that helps a 6-year-old build a daily plank habit. A puppy friend grows and she collects stickers.

- **Live app:** https://maxvdp-irl.github.io/mia-plank-pals/
- **Build plan:** [PLAN.md](PLAN.md). Specialist docs are in [docs/](docs/)

Vanilla HTML/CSS/JS PWA, hosted on GitHub Pages. All data stays on the device.
